# Scope accessibility

Last updated: 12 November 2026

Scope follows the macOS accessibility settings rather than adding its own. This page says what each one does in Scope, and where the limits are. If something here does not work as described, email support@ayeo.io.

## VoiceOver

- Every folder and file with a label in the map is a button. VoiceOver reads its name, size and kind ("Movies, 47.4 GB, folder"), presses it to zoom in, and opens its menu with VO-Shift-M for Copy Path and Reveal in Finder.
- The arrow keys move between items and VoiceOver follows. The selected item is the one the toolbar's Reveal and Trash act on, and VoiceOver reads it as selected.
- The chart rotor plays the folder you are in as an Audio Graph: its children by size, each named.
- The sidebar lists every folder by size as a standard outline, so you can read the whole disk without the map.
- The 3D map is not readable item by item. It announces the same summary as the flat map and points you to the sidebar, which holds the same entries. The flat map is the default view.

## Voice Control

Map items are named by their folder or file name alone, so "Show names" offers "Movies" and you say that. The toolbar, sidebar, sheets and menus are standard macOS controls with names.

## Keyboard

Everything in the map works from the keyboard: arrow keys move, Return zooms in, Escape or ⌘↑ goes back up, Control-Return or the Menu key opens the item's menu, ⌘⌫ moves it to the Trash and ⌘Z puts it back. The View menu lists every shortcut.

## Dark Mode

Scope follows the system appearance. Every colour in the map and the chrome has a light and a dark value.

## Differentiate Without Colour

With this setting on, each colour group in the map gets its own pattern as well as its colour: lines, dots or a grid for each file type and each age band. The legend shows the same patterns, and the info strip names the group in words.

## Increase Contrast

Text in the map reaches 4.5:1 against every fill by default and 7:1 with Increase Contrast on. Borders, hairlines and the capacity bar take stronger values with the setting on, as the system's own controls do.

## Reduce Motion

With this setting on, map items do not slide when the layout changes, a zoom fades instead of animating, the 3D map's blocks take their new heights at once, and the scanning spinner stands still.

## Text size

macOS has no system-wide text size setting for apps of this kind, so App Store Connect does not offer the Larger Text label on Mac. Scope draws its text with the system text styles, so it follows the sizes macOS gives them. ⌘+ and ⌘- zoom the map itself.

## Pointer

The map works without precise pointing: a press and drag scrubs across it and snaps to the entries large enough to point at.
